# 🎉 Feliz Cumpleaños Itzel

Página de cumpleaños para Itzel, hecha con HTML, CSS y JavaScript (sin dependencias).

## Ver en internet

Publicada con **GitHub Pages**:

👉 https://minami73.github.io/itzelita-birthday/

## Cómo se actualiza

El sitio se publica desde la rama `main`. Para actualizarlo:

```bash
git add .
git commit -m "Descripción del cambio"
git push origin main
```

GitHub Pages tarda uno o dos minutos en reflejar los cambios. Si no los ves, recarga con `Ctrl + F5`.

## Estructura

- `index.html`: estructura de la página
- `styles.css`: estilos y animaciones
- `script.js`: intro, confeti, carta de Juli y Mili y sorpresa final
- `images/`: fotos y personajes
- `sounds/`: música de fondo y efectos
